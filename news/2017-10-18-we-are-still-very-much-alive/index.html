We are still very much alive

Yes, the project is alive: packages are updated almost daily, and daily ISOs fill in until the next release.

Hello!

We have received many questions as of late if the Lunar Linux project is still alive; the short answer to that is YES! Of course we can't deny the fact that we are a little short on manpower right now, but packages are getting updated pretty much every day. If you want to track the package updates, head over to our GitHUB page.

Work is also ongoing to release a new official ISO, but we don't have a firm release date set. While waiting for the official release we have been producing daily ISO's that can be used until then, after all it's only used to bootstrap your installation; Lunar Linux is as you know a rolling release distribution. The daily ISO's can be found here.

Don't hesitate to join our IRC channel #lunar on freenode if you have any questions, or if you just want to hang out with some nice people!

- The Lunar Team
