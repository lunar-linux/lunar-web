About

colord is a system service that makes it easy to manage, install and generate color profiles to accurately color manage input and output devices.

What lin asks

Lin asks these before anything compiles, so you can walk away while it builds: which optional modules to use, and how to build it.

  3. Argyllfor ArgyllCMS sensor support
