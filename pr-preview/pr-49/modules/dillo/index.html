About

Dillo is a very fast, extremely small Web browser that's completely written in C. The source and binary are less than 300 kilobytes each. It renders a good subset of HTML, excluding frames, JavaScript, and JVM support.

What lin asks

Lin asks these before anything compiles, so you can walk away while it builds: which optional modules to use, and how to build it.
