About

Geeqie has been forked from gqview project, because it was not possible to contact gqview author and the only maintainer. * EXIF, IPTC and XMP metadata browsing and editing * interoperability, easy integration with other software * geeqie works on files and directories, there is no need to import images * fast preview for many raw image formats * tools for image comparison, sorting and managing photo collection

What lin asks

Lin asks these before anything compiles, so you can walk away while it builds: which optional modules to use, and how to build it.

  1. exiv2enhanced exif support
  2. luajitfor lua scripting support
  3. libheiffor SVG image support
  4. lcms2for color management support
  5. libjxlfor the jpeg xl ecnoder/decoder support
  6. LibRawfor raw file support
  7. libwebpfor WEBP image display
  8. ffmpegthumbnailerto display thumbnails of video files
  9. librsvgfor svg support
  10. ImageMagickfor additonal image support
  11. gphoto2for image support
  12. Image-ExifToolfor metadata support
