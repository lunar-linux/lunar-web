About

Calibre is a e-book library management application. Calibre is meant to be a complete e-library solution and thus includes library management, format conversion, news feeds to ebook conversion as well as e-book reader sync features.

What lin asks

Lin asks these before anything compiles, so you can walk away while it builds: which optional modules to use, and how to build it.

  1. popplerfor convertinf pdf files to html
  2. help2manfor manpages build and install
  3. speech-dispatcherfor speech support
