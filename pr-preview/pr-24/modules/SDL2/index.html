About

SDL is a library that allows you portable low-level access to a video framebuffer, audio output, mouse, and keyboard. With SDL, it is easy to write portable games which run on Linux (x86, Sparc, PPC, Alpha), Solaris (Sparc), Win32 (95, 98, NT), BeOS (x86), and MacOS (PPC).

What lin asks

Lin asks these before anything compiles, so you can walk away while it builds: which optional modules to use, and how to build it.

  1. systemdfor udev support
  2. alsa-libfor Advanced Linux Sound Architecture support
  3. pulseaudiofor PulseAudio audio support
  4. pipewirefor Pipewire audio support
  5. esoundfor Enlighted Sound Daemon supportdefault no
  6. nasfor Network Audio System supportdefault no
  7. libX11for X11 video driver
  8. mesa-libfor Mesa GL support
  9. waylandfor Wayland video driver
  10. DirectFBfor DirectFB video driver Say no if you want to compile ogre
  11. Use POSIX threads for multi-threading?default yes
