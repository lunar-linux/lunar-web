About

Exiv2 is a C++ library and a command line utility to access image metadata.

What lin asks

Lin asks these before anything compiles, so you can walk away while it builds: which optional modules to use, and how to build it.

  1. brotlifor using Brotli for JPEG XL compressed boxes (BMFF)
  2. gettextfor NLS support
  3. curlfor curtl support
