About

The XOrg foundation's open sourced public implemetation of X11 (the XOrg Server) is the offical reference implementation of the X Window System.

What lin asks

Lin asks these before anything compiles, so you can walk away while it builds: which optional modules to use, and how to build it.

  1. libgcryptfor SHA1 implementation
  2. libunwindfor call-chain library supportdefault no
  3. Enable suid wrapper (needed by some user-space mode-setting drivers like NVIDIA and VESA)?default yes
  4. Enable IPv6?default yes
