Build your Linux from source.

Lunar compiles every package on your machine, with the options you pick. One command, lin, keeps it simple.

Download Lunar Read the docs

Why Lunar Linux

A source-based system without the busywork. Pick a feature to see the command behind it.

More about Lunar

# choose compiler optimizations once, in a menu

$ lunar optimizelunar optimize

Set your optimizations once and every package you install afterwards is compiled with them, so the whole system is tuned for your CPU.

Get Lunar Linux

From the ISO to your first compiled package in three steps.

All downloads

    Download the ISO

    The 1.8.0 daily build, a bootable installer for 64-bit PCs.

    Download ISO (x86_64) Verify the checksum
  2. 2

    Install

    Boot the ISO and let the installer set up disks, a kernel and a minimal base system.

    Read the installation guide
  3. 3

    Build your first package

    lin downloads the source, resolves dependencies, compiles and installs it.

    $ lin nano
