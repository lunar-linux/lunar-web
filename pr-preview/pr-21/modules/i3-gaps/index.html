About

i3-gaps is a fork of i3wm tiling window manager extended with a few more features.

What lin asks

Lin asks these before anything compiles, so you can walk away while it builds: which optional modules to use, and how to build it.

  1. i3lockFor locking the screen
  2. i3statusStatus bar output
  3. dmenuDynamic menu support
