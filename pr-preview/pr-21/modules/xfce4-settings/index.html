What lin asks

Lin asks these before anything compiles, so you can walk away while it builds: which optional modules to use, and how to build it.

  1. libX11for Xorg-based windowing systems
  2. libXrandrfor X render supportdefault yes
  3. upowerfor device power control supportdefault yes
  4. libnotifyfor notification supportdefault yes
  5. colordfor colord supportdefault yes
  6. libXcursorfor X cursor supportdefault yes
  7. libinputfor X libinput driver supportdefault yes
  8. libxklavierfor keyboard layout selection supportdefault yes
  9. libcanberrafor sound controldefault yes
  10. waylandfor Wayland-based windowing systemsdefault no
  11. Enable support for embedded settings dialogs?default no
