About

SASL is the Simple Authentication and Security Layer This is the Cyrus SASL API implentation. It can be used on the client or server side to provide authentication. See RFC 2222 for more information. The following mechanisms are included in this distribution: * ANONYMOUS * CRAM-MD5 * KERBEROS_V4 * PLAIN * SCRAM-MD5 (deprecated) * GSSAPI (MIT Kerberos 5 or Heimdal Kerberos 5) * DIGEST-MD5 * LOGIN (unsupported) * SRP (unsupported, may not work)
