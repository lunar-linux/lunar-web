Daily build · x86_64

Lunar 1.8.0

Built November 13, 2026 under a waxing crescent.

Download the ISO (x86_64) SHA-256 checksum next to the ISO

Install in three steps

  1. Download the ISO and write it to a USB drive.
  2. Boot it and run the installer. The installation guide walks you through disks, the kernel and the base system. Check the system requirements first.
  3. Build your first package with lin nano. Package management explains the rest.

Verify the download

Every ISO has a checksum file next to it in the same folder. Download both, then run this in that folder:

sha256sum -c lunar-1.8.0-daily-*-x86_64.iso.sha256

OK means the ISO arrived intact. Older releases ship SHA-1 or MD5 files instead; check them the same way with sha1sum -c or md5sum -c.

Development builds

The daily build is a snapshot of the upcoming 1.8.0 release. Each new build replaces the previous one in the daily folder.

  • 1.8.0 release candidate 1: an earlier test build from July 2019, kept in the testing folder. The daily build is newer.

Older releases

1.7.0, from October 2014, is the last numbered release. Its images are xz-compressed; unpack one with xz -d before writing it to a USB drive.

  • 1.7.0 for x86_64: 64-bit PCs, 361 MB (SHA-1)
  • 1.7.0 for i686: 32-bit PCs, 338 MB (SHA-1)
  • 1.5.1 to 1.6.5: bzip2-compressed images with MD5 or SHA-1 checksums, in the main download folder
  • 1.4.0 and 1.5.0: the oldest images, in the ISO archive

Source code

Lunar is developed in the open on GitHub.

  • lunar: the package manager, with lin, lunar and friends
  • moonbase-core: the modules for the base system
  • moonbase-other: the wider collection of modules
  • moonbase-xorg: the X.Org display server
  • moonbase-kde, moonbase-gnome, moonbase-gnome3, moonbase-xfce, moonbase-efl: desktop environments
  • lunar-tools: system administration tools such as lnet and clad
  • lunar-iso: the scripts that build these ISO images

The download server also carries a moonbase snapshot as a single archive and a source mirror with copies of upstream source tarballs.
