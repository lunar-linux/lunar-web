Why Lunar Linux

A source-based system without the busywork. Pick a feature to see the command behind it.

More about Lunar

# choose compiler optimizations once, in a menu

# rebuild a package and pick its optional dependencies again

# install several packages in one go

# fetch the latest moonbase and rebuild what changed

$ lunar optimizelunar optimize

Set your optimizations once and every package you install afterwards is compiled with them, so the whole system is tuned for your CPU.

Lunar asks about optional features when it builds a package. Changed your mind later? Reconfigure and rebuild it with one command.

No hand-run configure and make: lin downloads the sources, works out the dependencies, compiles and installs, and tracks everything for clean removal with lrm.

Your system contains only the packages you chose. Updating pulls the latest package definitions and recompiles whatever has a newer version.
