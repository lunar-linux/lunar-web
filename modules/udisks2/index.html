About

Udisks is an abstraction for enumerating power devices, listening to device events and querying history and statistics. Any application or service on the system can access this service via the system message bus.

Supports creating LUKS 2 encrypted devices and other LUKS-related enhancements.

It is a replacement for udisks. It it NOT backwards compatible.
