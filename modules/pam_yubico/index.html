Yubico Pluggable Authentication Module (PAM).

What lin asks

Lin asks these before anything compiles, so you can walk away while it builds: which optional modules to use, and how to build it.

  1. ykpersfor challenge-response support (requires yubikey 2.2 or later)
  2. openldapfor LDAP support
