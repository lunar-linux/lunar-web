About

Octave is a high-level interactive language, primarily intended for numerical computations that is mostly compatible with MATLAB. Octave can do arithmetic for real and complex scalars and matrices, solve sets of nonlinear algebraic equations, integrate functions over finite and infinite intervals, and integrate systems of ordinary differential and differential-algebraic equations.

What lin asks

Lin asks these before anything compiles, so you can walk away while it builds: which optional modules to use, and how to build it.

  1. fftwfor system fftw support
  2. %JAVA_SDKfor java support
  3. fltkfor fltk support
  4. arpack-ngfor eigen value operations
  5. qrupdatefor fast QR & Cholesky updating functions
  6. readlinefor readline support
  7. curlfor curl support
  8. hdf5for hdf5 support
  9. glpkfor linear programming support
  10. texliveto generate documentationdefault no
  11. gperfif you need to recreate oct-gperf.h
  12. gl2psfor OpenGL printing supportdefault no
  13. GraphicsMagickfor reading and writing images
  14. SuiteSparsefor matrix support (Recommended)
  15. qhullfor qhull support
