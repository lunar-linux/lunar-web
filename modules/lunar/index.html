lunar58

lunar contains the package management tools for Lunar-Linux.

$ lin lunar

Needs 24 modules (85 counting theirs), can use 7 more. Nothing depends on it.

About

lunar - Tools package management by source.

lunar includes the following files: /etc/lunar/config /etc/lunar/dialogrc /etc/lunar/local /etc/lunar/mirrors configuration files. /usr/share/doc/lunar/COPYING-2.0 /usr/share/doc/lunar/CVS /usr/share/doc/lunar/ChangeLog /usr/share/doc/lunar/Changelog /usr/share/doc/lunar/README /usr/share/doc/lunar/contributions /usr/share/doc/lunar/gpl.html documentation, please read /usr/sbin/lunar menu driven interface /usr/sbin/lget downloads modules sources /usr/sbin/lin installs modules /usr/sbin/lrm removes modules /usr/sbin/lvu provides information about the box /var/lib/lunar/excluded list of files that are ignored /var/lib/lunar/protected list of files that will not be deleted /var/lib/lunar/subroutines common subroutines

and man pages.

What lin asks

Lin asks these before anything compiles, so you can walk away while it builds: which optional modules to use, and how to build it.

  1. nanofor a ultra-small editor
  2. lunaric-soundto have lunar signal events with sound
  3. opensshto use cabal multi-box system administration
  4. cvsto be able to download cvs sources
  5. subversionto be able to download svn sources
  6. ccachefor caching builds
  7. TimeDateto display last compile time in lvu info
