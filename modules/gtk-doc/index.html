About

GTK-Doc is used to document C code. It is typically used to document the public API of libraries, such as the GTK+ and GNOME libraries, but it can also be used to document application code.

What lin asks

Lin asks these before anything compiles, so you can walk away while it builds: which optional modules to use, and how to build it.

  1. dblatexfor PDF support
  2. jadetexfor SGML support (use this or openjade not both)
  3. openjadefor SGML support
