About

GTK+ is a multi-platform toolkit for creating graphical user interfaces. Offering a complete set of widgets, GTK+ is suitable for projects ranging from small one-off projects to complete application suites.

What lin asks

Lin asks these before anything compiles, so you can walk away while it builds: which optional modules to use, and how to build it.

  1. cupsenable CUPS as print backend
  2. colordenable colord support for CUPS
  3. %Xfor the X11 backend (recommended)default yes
  4. wayland-protocolsfor the wayland backenddefault yes
  5. libcloudprovidersfor cloud storage supportdefault no
  6. Enable broadway HTML5 backend? (Run GTK+ apps in a browser)default no
