About

Linux-PAM provides a flexible mechanism for authenticating users. PAM was invented by SUN Microsystems.

What lin asks

Lin asks these before anything compiles, so you can walk away while it builds: which optional modules to use, and how to build it.

  1. gettextfor i18n internationalization support
  2. Re-lin all Linux-PAM aware MODULEs?default yes
