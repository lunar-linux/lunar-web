About

Poppler is a PDF rendering library based on the xpdf-3.02 code base.

What lin asks

Lin asks these before anything compiles, so you can walk away while it builds: which optional modules to use, and how to build it.

  1. poppler-datafor support of additional file encodings
  2. boostEnable to use boost for Splash backenddefault no
  3. openjpeg-2for using system's libopenjpeg for JPX streams, Say no on first install
  4. libjpeg-turbofor using system's jpeg library for DCT streams
  5. curlfor curl based HTTP support
  6. libpngfor PNG image support
  7. tifffor TIFF image support
  8. cairofor the cairo graphics backend
  9. qt5for Qt5 wrapper support
  10. qt6-basefor Qt6 wrapper support
  11. Use single presision for Splash backend?default yes
  12. Build poppler cpp wrapper? (cups-filters needs it)default yes
  13. Build command line utils?default yes
