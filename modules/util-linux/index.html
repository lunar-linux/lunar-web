About

Util-linux is a suite of essential utilities for any Linux system. Its primary audience is system integrators and DIY Linux hackers. Util-linux is attempting to be portable, but the only platform it has been tested much on is Linux i386.

What lin asks

Lin asks these before anything compiles, so you can walk away while it builds: which optional modules to use, and how to build it.

  1. pythonfor Python 3 supportdefault yes
  2. sqliteto enable liblastlog2
  3. Linux-PAMfor PAM support
  4. cryptsetupfor disk encryption support
