About

PostgreSQL is a sophsticated Object-Relational DBMS, supporting almost all SQL constructs, including subselects, trasactions and user defined types and functions.

What lin asks

Lin asks these before anything compiles, so you can walk away while it builds: which optional modules to use, and how to build it.

  1. llvmbuild with LLVM based JIT support
  2. %OSSLfor SSL connections
  3. perlfor perl programming
  4. pythonfor python programming
  5. Linux-PAMfor user authentication
  6. %KERBEROSfor gssapi supportdefault no
  7. openldapfor ldap support
  8. timezone-datause system timezone datadefault yes
